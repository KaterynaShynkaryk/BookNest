# BookNest

A web application for managing a personal library that allows users to add books, track reading status, search, and take notes on read or planned books.

## Running locally

From the project root, start the Django development server with:

```bash
python manage.py runserver
```

## Demo user

Create or refresh a demo account with sample books, shelves, and notes:

```bash
python manage.py seed_demo_user
```

Default credentials:

- Username: `demo`
- Password: `demo12345`
